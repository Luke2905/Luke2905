### Sobre Mim

Sou apaixonado por construir soluções eficientes que unem a lógica de negócios à excelência técnica. Minha jornada me levou do planejamento operacional até a engenharia de software e análise de dados. Essa trajetória me permite não apenas codificar, mas entender as necessidades reais dos usuários e criar sistemas e painéis que impactam diretamente a tomada de decisão corporativa.

* **Formação:** Técnico em Desenvolvimento de Sistemas & Cursando Informática para Negócios (Fatec SBC).
* **Foco Atual:** Arquitetura de sistemas modulares, integrações de APIs REST e dashboards interativos.
* **Projeto em Destaque:** Desenvolvendo um sistema de Gestão Preditiva de Ativos de TI e Ciclo de Vida de Hardware.
* **Filosofia:** Escrever código limpo (Clean Code), priorizar a performance e gerar valor através de interfaces intuitivas.
